# NexusCloud Pricing Details

## Free Tier — $0/month

- **Storage**: 5GB object storage
- **Compute**: 1 vCPU, 1GB RAM
- **Bandwidth**: 10GB/month outbound transfer
- **API Rate Limit**: 100 requests per minute
- **Support**: Community forum and email (48-hour response time)
- **Regions**: US-East only
- **No credit card required** to sign up

## Pro Tier — $29.99/month

- **Storage**: 100GB object storage + 50GB block storage
- **Compute**: 4 vCPU, 8GB RAM
- **Bandwidth**: 500GB/month outbound transfer
- **API Rate Limit**: 1,000 requests per minute
- **Support**: Email (24-hour response) + live chat during business hours (9 AM - 6 PM ET, Mon-Fri)
- **Regions**: US-East, US-West, EU-Central
- **Additional features**: Auto-scaling, custom domains, SSL certificates, 99.9% uptime SLA
- **Overage charges**: $0.25 per GB beyond included storage

## Enterprise Tier — $99.99/month

- **Storage**: 500GB object storage + 200GB block storage
- **Compute**: 16 vCPU, 32GB RAM
- **Bandwidth**: 2TB/month outbound transfer
- **API Rate Limit**: 10,000 requests per minute
- **Support**: 24/7 phone support + dedicated account manager
- **Regions**: US-East, US-West, EU-Central, AP-Southeast
- **Additional features**: Dedicated tenancy, advanced DDoS protection, custom SLA, priority feature requests, 99.99% uptime SLA
- **Overage charges**: $0.10 per GB beyond included storage

## Annual Billing Discount

All paid plans offer a 20% discount when billed annually. Pro annual is $287.90/year (saves $71.98). Enterprise annual is $959.90/year (saves $239.98).

## Custom Plans

For organizations needing more resources, contact sales@nexuscloud.io for custom pricing and volume discounts.
